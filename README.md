# 📂 File Storage Manager

## About the Project

File Storage Manager is a simple web-based project built using HTML, CSS, and JavaScript. It allows users to select and upload files through a simple and user-friendly interface.

## ✨ Features

* Select files from your computer.
* Upload files using the Upload button.
* Display selected files in the Stored Files section.
* Simple and user-friendly design.
* Easy to use for beginners.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📁 Project Structure

```text
File-Storage-Manager/
│
├── file.html
├── file.css
├── file.js

```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `file.html` in your browser.
4. Select a file and click the Upload button.

## 🎯 Project Objective

The objective of this project is to practice HTML, CSS, and JavaScript by creating a simple file management interface.
